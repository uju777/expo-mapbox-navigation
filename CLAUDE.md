# expo-mapbox-navigation

> Expo 모듈 — Mapbox Navigation SDK 래퍼

## 기술 스택
- TypeScript (Expo Module)
- Swift (iOS), Kotlin (Android)
- Mapbox Navigation SDK

## 주요 파일
- `src/` — TypeScript 모듈 소스
- `ios/`, `android/` — 네이티브 코드
- `example/` — 예제 앱
- `plugin/` — Expo Config Plugin

## 빌드
```bash
npm run build      # expo-module build
npm run clean      # expo-module clean
```
